# 工作单元报告 · Round-3 故事线主线/支线治理（v1.8.12）

> 瑞宝宝原话核心：开了太多不明所以的主线；主线要贯穿几十章到几百章，支线才服务主线；小事件（对话/发现/去某地）不该单独开线；主线七要素默认不填，等推进完再自动填；主线下面的支线/章节/时间轴可以收起来。

## 一、干了什么（一句话）

把"龙陨之地·新城篇"里**错开的 3 条平级主线收敛成 1 条真主线 + 12 条支线**，并在**生成逻辑里加了硬约束**——以后 AI 再生成时，只要有活跃主线就只许产支线、绝不多开主线，小事件也不再被建成独立线。

## 二、为什么这么做（第一性原理）

瑞宝宝指出的不是小毛病，是**故事线层级的根基错了**：

- **主线是什么**：市面创作共识（已查：头条/潇湘书院等写作干货）= 贯穿全书的核心目标线，像大树主干，撑得起数十章到数百章，拔掉这段剧情故事就不成立。一个项目通常只有 1 条。
- **支线是什么**：由主线触发、服务主线、可独立收束的小故事，像树枝；拔掉它故事照样成立。
- **之前错在哪**：AI 生成时把"掩埋之钥""龙元裂缝第七白日"这种**只够当支线内容**的东西开成了平级主线（落库代码无条件把 LLM 返回的 main 建成新主线，等于默认允许无限开主线）。左侧列表因此堆了 3 条主线，看起来"不明所以"。

所以治理分两层：**先收拾已有的脏数据** + **从根上堵住以后再生**。

## 三、用了什么方法、效果如何

### 1. 数据层收拾（已备份后执行）
- 备份脚本导出全量 storylines+events 到 JSON（防丢失）。
- 把 `龙元裂缝的第七个白日`、`掩埋之钥` 从 `main` 降级为 `side`，parent 挂到真主线 `龙陨之地·主线`。
- 把原本挂在这两个假主线下的 10 条支线，parent 统一改挂真主线。
- 结果：**1 条主线 + 12 条支线全部归其下，0 游离支线**。
- 主线时间轴填 3 个"汇聚性大事件"（新城初醒 / 掩埋之钥 / 龙元裂缝第七白日），把 12 条支线的精华收进主线脉络；每条支线各填 1 个代表事件（证明"事件能填、记忆不丢"）。

### 2. 生成逻辑加硬约束（治本，不依赖 LLM 听话）
改了 3 个文件：
- `src/app/api/storylines/generate/route.ts`（落库唯一入口）：
  - **强制降级**：已有活跃主线且非 newMain 模式时，LLM 返回的任何 `main` 都强制转 `side` 并挂回主线——从源头杜绝多开主线。
  - **主线七要素留空**：`type==="main"` 时 `sevenElements` 全空（符合"大主线默认不填"）。
  - **prompt 强化**：加"主线/支线铁律"——主线定义、支线服务主线、拔剧情判断法、小事件不入线、已有主线只许产支线。
- `src/core/storyline/generate.ts`（真后台生成路径的 prompt 源头）：同步强化 prompt + 主线七要素空 + 双保险降级（带 status 区分 active/completed，避免"前主线完结需开新主线"被误降）。
- `src/core/storyline/execute-task.ts`：把 storyline 的 `status` 传给生成上下文，让降级判断能区分"活跃主线"和"已完结主线"。

### 3. UI 层（发现已有，无需重做）
`StorylineList.tsx` 在 Round-2 前**已经实现了树形折叠**：主线常显、支线默认收起、点箭头展开。数据合并后左侧立即变成"1 主线 + 12 条可收起支线"，瑞宝宝要的"收起来"天然满足。

## 四、验证（多测试、看效果）

- **双门禁**：`tsc` 0 错；`vitest` 43 文件 368 测试全绿。
- **无头 DOM 断言**（确凿证据，非肉眼）：
  - `龙陨之地·主线` 存在 ✓
  - 主线进度条出现次数 = 1（支线收起不渲染）✓
  - `掩埋之钥`/`龙元裂缝第七白日` 不再作为平级主线显示 ✓
  - 默认收起（不显示支线名）✓；点开箭头后 12 条支线全部出现 ✓
  - 控制台零报错 ✓

## 五、关键取舍（诚实标注）

- **降级放在落库层而非只靠 prompt**：LLM 会"不听话"多开主线，落库层强制降级是最后一道闸，100% 可靠。prompt 强化是源头减少，双保险。
- **主线七要素留空**：瑞宝宝明确"大主线默认不填，等推进完再自动写"。本轮只做到"默认空"，**自动回填主线七要素的逻辑尚未实现**（需后续在 AI 推进/缝合怪节点加"主线完结→回填七要素"）。支线七要素正常填。
- **完整三栏因果链 + 推进/试探墙**仍是 v1.9 目标态（透镜排期），本轮未动。
- **小事件不入线**已通过 prompt 约束 + 落库降级覆盖；但"把小事件自动转成主线时间轴事件"是生成时的 LLM 行为，需实际跑一次 AI 生成才能肉眼确认分布——本轮用逻辑审查 + 双门禁保证，未实跑 LLM（避免污染测试库）。
