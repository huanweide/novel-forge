# P3 删 UI 噪声 · 本地目测验收清单（v0.46.86）

> 沙箱无 Chromium / 显示，本清单供你在本地 `npm run dev`（端口 3001）逐项勾验。
> 每个检查点给出「正常表现」与「异常表现」；发现异常请截图 + 描述回传，我定位修复（精准到行）。
> 涉及文件：Toolbar.tsx / LeftPanel.tsx / RightPanel.tsx / PostGenPanelTabs.tsx。

## 0. 启动
- [ ] `cd novel-forge && npm run dev`，打开 http://localhost:3001
- [ ] 进入任一项目的写作页 `/workspace/<projectId>`
- [ ] 浏览器控制台无 P3 相关新增报错（本次仅改 UI，不应有运行时错误）

## A. 顶栏收敛（Toolbar.tsx）
可见按钮应为 7 个：文风 / 大纲 / 摘要 / 导入书稿 / 备份包 / 导出▾ / 更多▾
- [ ] A1 顶栏只显示上述 7 个入口，无重复、无丢失
- [ ] A2 点「导出▾」→ 下拉含「导出文件」「复制全文」
- [ ] A3 点下拉外部（半透明遮罩）→ 菜单关闭
- [ ] A4 点「更多▾」→ 下拉含「自动化」「工具箱」
- [ ] A5 自动化 / 工具箱面板能正常打开、关闭
- [ ] **A6 风险点**：下拉菜单最末项是否完整可见？若顶栏或其父容器有 `overflow-hidden`，过高的菜单底部可能被裁切 → 重点验证「导出▾」「更多▾」各自最末一项不被切
- [ ] A7 功能验证：导出文件真能下载、复制全文真能复制全文

## B. 右栏监测折叠（RightPanel.tsx）
监测 tab 三面板：叙事能量曲线 / 生成延迟 / 节点监测，默认全部收起
- [ ] B1 监测 tab 默认显示三个可点标题栏（带 `▸` 折叠指示），均收起
- [ ] B2 点任一标题 → 展开对应面板；再点 → 收起
- [ ] **B3 风险点**：展开内容（尤其能量曲线 SVG 折线）在右栏窄宽下是否完整、无横向裁切
- [ ] B4 省开销验证：三个面板都收起时，打开 DevTools → Network，确认无对应 fetch 请求（折叠不挂载子组件，非仅 `hidden`）
- [ ] B5 切到其它 tab 再回监测 → 记录折叠状态行为（重置 / 保留均可，记录即可）

## C. 左栏精简（LeftPanel.tsx）
可见 tab 应为 4 个：大纲 / 角色(N) / 世界(N) / 更多▾
- [ ] C1 左栏只显示上述 4 个入口
- [ ] C2 点「更多▾」→ 下拉含「故事线(N)」「规则」
- [ ] C3 点故事线 / 规则 → 切到对应内容，渲染正常（功能零丢失，仅入口收起）
- [ ] C4 当 activeTab 落在隐藏 tab（故事线 / 规则）时，「更多▾」高亮（moreActive）
- [ ] **C5 风险点**：左栏 `w-64` 容器 `overflow-hidden`，下拉菜单是否在栏内完整显示、不被裁切；遮罩点击关闭是否正常

## D. 后处理高级折叠（PostGenPanelTabs.tsx）
主行应为：章节提取 + 高级▾（其余 4 个收进第二行）
- [ ] D1 后处理面板首行只有「章节提取」+「高级 ▾」
- [ ] D2 点「高级 ▾」→ 第二行展开 4 个 tab（废词检测 / 逻辑自查 / 本地蒸馏 / 审校）
- [ ] D3 再点「高级 ▾」→ 第二行收起
- [ ] D4 若某高级 tab 有异常（hasIssues）→ 「高级」入口显红点角标
- [ ] **D5 风险点**：PostGenPanel 容器（约 181 行）`overflow-hidden`，双行展开是否在容器内完整、底部不被切（这是用「双行」而非「下拉」的根因）；5 个 tab 全有内容时双行换行是否拥挤

## E. 交叉 / 回归
- [ ] E1 全屏 / 窄屏下，顶栏 7 按钮不溢出、不异常换行
- [ ] E2 原有功能入口未因「收起」而丢失：抽卡 / 记忆衰减 / 拆解页仍在原处可访问
- [ ] E3 各处下拉 / 折叠的键盘可达性（Tab / Enter / Esc）记录即可，非阻塞

## 异常反馈方式
发现裁切 / 层叠 / 功能丢失 → 截图 + 描述（哪个组件、什么操作、什么异常）回传，我定位修复。
**重点怀疑区**：
1. 顶栏下拉菜单高度超容器（A6）
2. 后处理双行底部被切（D5）
3. 左栏下拉在 `overflow` 栏内完整性（C5）
