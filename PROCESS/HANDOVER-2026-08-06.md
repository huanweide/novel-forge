## 0. 一句话定位

novel-forge 是一个**本地运行的 AI 小说创作平台**（类比 SillyTavern，不是 SaaS），技术栈 Next.js 16 + React 19 + Tailwind v4 + Prisma 7 + PostgreSQL 17，dev 端口 3001。它通过 LLM 自动写章、自动填世界书/角色卡、管理故事线，目标是同时服务「靠小说赚钱的创作者」和「为兴趣写作的用户」。分发方式是 `git clone` + 创意工坊 `.preset.json`，单用户无鉴权，LLM 配置存在数据库 `AppSettings`。

## 3. 使用的工具与 skills（维度三）

### 3.1 Skills（按使用频率）

| Skill | 用途 | 何时用 |
| --- | --- | --- |
| **infinite-refine-loop（Overlord 魔王系统）** | 主推进机制：6 人格只读诊断 → Chair 派 Agent 并行实现 → 统一门禁 → 升版 | 任何「建站 + 持续迭代」型任务；本项目默认走它，**不走路 dev-pipeline** |
| **dev-pipeline** | 单次改动质检（Low/Med/High + FAST 档） | 仅在 infinite-refine-loop 的 FAST 档覆盖时用，或孤立小改动 |
| **novel-forge-diagnostic** | 写码后强制自检（tsc / Prisma / React 反模式） | 每次写完代码、改 API 路由或组件后必须调用 |
| **maxloop-overlord** | 正式版深度体验 + 集体评审迭代 | 需要对正式版做大规模体验/评审时 |
| **frontend-mastery** | 前端美化、UI 设计系统 | 面板/视觉重构 |
| **agent-browser** | 浏览器自动化、截图核查 | 需要真实点击/截图验证 UI 时（沙箱有独立 Chrome） |

### 3.2 工具与命令

- **git**：提交用 `git add` + `git commit`；**推送必须走代理**：`git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 push origin main`（直连必 `Connection reset`，见 ERRORS.md E009）。
- **tsc 门禁**：`SAFE_DELETE_DISABLE=1 npx tsc --noEmit`（零错误才允许升版）。
- **vitest**：`npx vitest run`（include 为 `src/**/*.test.ts`）。
- **Prisma 7**：新增模型/字段后必须 `npx prisma db push` + `PRISMA_DISABLE_SAFE_DELETE=1 npx prisma generate`。
- **code-explorer 子代理（Explore）**：大范围并行侦察源码，结果不进主上下文，省 token。
- **DB 探测**：Prisma 7 的 `db execute` 不回显结果，改用 `node + pg` 写 `probe.cjs` 探测（见 ERRORS.md E002）。

- **新坑前先扫 `ERRORS.md`**（见维度五），避免重踩已知坑。
- **dev-pipeline 过度审查已改为 FAST 档**（E007），不要对每个小改动跑全量重审查。

### 4.2 升版双 changelog 流程（每次必做）

1. 改 `src/lib/changelog-data.ts`：在 `VERSIONS` 数组**最前面**插入新版本条目，改 `LATEST_VERSION`，改 `CHANGELOG_BRIEF`（4 条）。
2. **字符串内严禁英文双引号 `"`**（会触发 TS1005 断串），中文强调用「」。
3. 同步根 `CHANGELOG.md` 头条（同一版本内容，markdown 形式）。
4. **两个文件一起 `git add` + 同一 commit**，缺一不可。
5. `tsc` 零错误 + `vitest` 全绿后，代理 push。

## 5. 领悟到的经验（维度五：ERRORS.md 精华）

以下是踩坑库 `ERRORS.md` 的九条，接手前必读：

- **E001 新增字段漏进 autofill 表单重建**：加 DB 字段后，全局搜 `setForm`/`useState`/提交体，确认前端表单也加了，否则填表丢字段。
- **E002 Prisma 7 `db execute` 不回显**：改用 `node + pg` 写 `probe.cjs` 直接查库。
- **E003 端口 3001 被遗留 dev 占用**：`Get-NetTCPConnection -LocalPort 3001` 探活，杀掉残留进程再起新 dev。
- **E004 PG IPv6 `::1` 触发 503**：`.env` 的 `DATABASE_URL` 用 `127.0.0.1:5432`，**勿用 `localhost`**。
- **E005 Safe-Delete 拦截 build/dev**：`.env` 勿加 `NODE_OPTIONS`；重启用 `CODEBUDDY_SESSION_ID= npm run dev`；build 用 `NODE_OPTIONS="--use-system-ca" npm run build`。
- **E006 串行逐文件 Read 过慢**：大范围侦察交给 code-explorer 子代理并行。
- **E007 dev-pipeline 过度审查**：已改 FAST 档，别再对每小改动全量审查。
- **E008 文档/代码字符串误用 ASCII 双引号 + 异常字符**：changelog 字符串禁用 `"`，用「」；提交前跑 tsc 门禁预防。
- **E009 git push 禁用代理直连 Connection reset**：**必须**走 `7897` 代理（见维度三命令）。

### 5.1 工程铁律（来自 maxloop 协议）

- **Chair 必须亲自单跑 tsc + vitest**：并行 Agent 各自跑 tsc 会报竞态假象，必须等全部写入后 Chair 亲跑。
- **Trust but verify**：Agent 可能空返回但改动已落地，也可能漏 `generate` 致 TS 错误。Chair 必须亲读 `git diff` + 跑 tsc + 跑 vitest，不轻信「已完成」回报。
- **绝不偷工减料/跳步/省略验证/缩水方案**：用户明示拥有无限 token 与整夜时间，细心优先于省钱。

### 5.2 业务关键事实

- **两套 jsonError**：`@/lib/api` 的 `jsonError(msg,status,code?)`（精确 4xx）与 `@/lib/api-error` 的 `jsonError(e)`（默认 500），别混用。
- **HTTP header 严禁中文**（ByteString 500）：文件名下载用 RFC5987 `filename*=UTF-8''`。
- **LLM key 来自 DB `AppSettings`**（`getSettings()`），**不是 `.env` 的 `LLM_API_KEY`**。
- **世界卡类型定义碎片化在 4 处**（worldPanelData / types/index / settings/parser / tool-registry），新增模块必须四处同步 + 编辑下拉 + 填表映射 + 完整性校验。
- **CJK 词边界**（matchNameStrict）：2 字 CJK 直接子串命中不吞并；3 字+ CJK 走覆盖区间吞并。
- **确认流程两开关**（默认开）：`autoConfirmEnabled`（合格章自动定稿）+ `autoDeliverEnabled`（全书定稿后自动整本交付），统一 `maybeAutoDeliver(projectId)` 幂等。

## 7. 工作流程（维度七：Overlord 魔王系统）

本项目默认走 **infinite-refine-loop（Overlord 魔王系统）**，不走路 dev-pipeline。完整循环：

1. **6 人格只读诊断**：派 6 个只读 Agent（不同视角）并行诊断现状，产出诊断报告（不写码）。
2. **Chair 整合**：Chair（主 Agent）读 6 份报告，定 Top 修复清单，排优先级（P0/P1/P2）。
3. **派 Agent 并行实现**：Chair 派多个实现 Agent 并行改码（各自负责不同文件/模块）。
4. **统一门禁（Chair 亲跑）**：等全部写入后，`SAFE_DELETE_DISABLE=1 npx tsc --noEmit` 零错误 + `npx vitest run` 全绿。**绝不轻信子 Agent 的「已完成」**，亲读 `git diff`。
5. **升版双 changelog**：改 `changelog-data.ts` + 根 `CHANGELOG.md`，两文件同 commit。
6. **代理 push**：`git -c http.proxy=http://127.0.0.1:7897 ... push origin main`。
7. **记忆回写三件套**：追加当日 `.workbuddy/memory/YYYY-MM-DD.md` 日志 + 视情况更新 `MEMORY.md` + 必要时写费曼工作单元报告（`PROCESS/WORK_REPORT.md` 或本次式 `PROCESS/` 文档）。

### 7.1 用户级操作偏好（贯穿所有任务）

- **删除默认执行，不问**：改项目/网站文件时如需删除，直接删，不征求确认（个人目录 Desktop/Documents/Downloads 仍受安全规则约束）。
- **自主执行**：除非涉及外部发布/凭据等硬阻塞，否则不要反复问意见，按 pipeline 直接做。
- **集成优先**：在现有基础上先把原模板网站每个功能集成进来，再增强。
- **默认同意、减少互动**：汇报用通俗语言说清「做了什么 + 达成什么效果」，不要一步步问。
