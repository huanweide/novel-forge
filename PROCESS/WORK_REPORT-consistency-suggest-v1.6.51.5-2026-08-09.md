> 费曼式沉淀 · 零基础可读 · 瑞宝宝专属

## 一句话结论

给 B 任务（v1.6.51.4）做的「只标红不改写」补上了最后一块拼图：作者点一下冲突条目，AI 直接给出**可复制替换原文**的改写建议，但**绝不自动动正文**——创作主权始终在作者手里。本版零数据库结构变更，纯新增一个解析函数 + 一个 API 端点 + 面板上的「看建议」按钮。

## 二、为什么这么做（底层原理）

**问题从哪来**：B 任务能标红「这里和设定矛盾了」，但作者还得自己想「那我该怎么改」。对小白作者来说，标红只是告诉他「你错了」，不告诉「怎么改对」，体验断在半路。

**为什么不自动改正文**（第一性原理）：novel-forge 的定位是「作者主权工具」，不是「AI 代写」。马斯克 CEO 拍板的铁律就是「标红不改写」——AI 可以建议，但落笔必须是人。所以本版只产建议、给复制按钮，正文改不改、怎么改由作者定。

**为什么要单独写个解析纯函数**（第一性原理）：大模型返回建议时，经常前面带一句废话开场白（比如「以下是改写建议：」），或者把建议包在 ```代码围栏``` 里，或者直接甩一句「无建议」。如果不收拾，用户复制到正文里就会带上「以下是改写建议：」这种垃圾。这个函数就是专门把模型的「人话废话」提纯成「可直接粘贴的干净文本」。把它写成纯函数（不依赖数据库、不依赖网络），就能单独写单元测试锁死行为，不用每次都真去调一次模型。

**类比**（帮你秒懂）：
- 「一致性冲突」= 小说里前后打架的事实，像前 3 章写主角是「灰眼睛」，第 10 章写成「黑眼睛」了。
- 「基线事实」= 你早先定好的「官方设定」，像设定集里写的「主角灰眸」。标红就是拿新章节去跟设定集对，对不上就报警。
- 「修正建议」= AI 看你写错的那句，告诉你「把『黑眼睛』改成『灰眸』就行」，但动不动笔是你的事。

### 关键代码（已实测）

```ts
// 剥帽逻辑核心：仅去前缀，不吞正文
s = s.replace(
  /^(?:以下是|这是(?:给(?:你|您)的)?|给(?:你|您)的|建议如下|如下)?(?:改写建议|修改建议)?[:：]\s*/,
  "",
);
// 逐行收集，遇空行 / 结尾客套话停止
const collected: string[] = [];
for (const raw of s.split(/\n/)) {
  const line = raw.trim();
  if (!line) { if (collected.length) break; continue; }
  if (TRAILING_PLEASANTRY.test(line)) { if (collected.length) break; continue; }
  if (OPENING_HAT.test(line)) continue;
  collected.push(line);
}
return collected.join("\n").trim();
```

### 测试覆盖（5 例，全过）
1. 正常单行 → 原样返回
2. 带 ``` 代码围栏 → 剥掉围栏
3. 开场白 + 空白 + 真建议 + 结尾客套话 → 只留真建议（**本版修复点**）
4. 开场白与建议同行 → 只去前缀留建议（本版新增锁死）
5. 空响应 / 「无建议」 → 空串或「无建议」原样，不抛异常

## 四、关键取舍

**A. 为什么修函数而不是改测试？**
测试第 3 例期望「跳过开场白取真建议」才是用户真正想要的行为——用户点按钮要的是干净建议，不是「以下是改写建议：」这种废话。函数初版契约（取首个非空段落）太糙，把开场白当正文，是函数缺陷。改测试去迁就缺陷 = 把 bug 藏起来，违背「反自欺闸门」。所以修函数。

**B. 为什么用「逐行收集 + 客套话黑名单」而不是更复杂的 NLP？**
大模型输出形态有限且可枚举（开场白 / 围栏 / 结尾客套话），用正则黑名单足够覆盖 99% 场景，零依赖、零延迟、可单测。上 NLP 分词是杀鸡用牛刀，还会引入新不确定性。保持简单。

**C. 为什么零 schema 变更？**
建议是「按需生成、不落库」的——作者点了才调一次模型，不需要存。存了反而占库、还要管生命周期。按需即用最干净。

**D. 踩坑实录（真实，非推测）**
- 第一版 replace 正则写成了「引导词后必须紧接冒号」：`/^(?:以下是|...)[:：]/`。但真实文本是「以下是**改写建议**：」，引导词和冒号之间隔着「改写建议」，正则匹配失败，帽子没剥掉，测试照样挂。
- 修复：把正则改成「引导词 + 可选『改写建议/修改建议』+ 冒号」整体匹配：`/^(?:以下是|...|建议如下|如下)?(?:改写建议|修改建议)?[:：]\s*/`。这一改才真正剥掉帽子。
- 教训：**写正则前先把真实样本字符串在脑子里走一遍**，别想当然。
