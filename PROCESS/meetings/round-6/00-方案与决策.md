# Round-6 方案与决策（生成轻量化 + 填表后台化 + 故事线缝合怪）

## 用户核心诉求（本批）
1. 一键追评填表后台化（点完可关页面、有进度提示、不挡正文）
2. 角色卡「自动去重合并」按钮（去重/合并/去龙套，tooltip 介绍，结果弹窗确认）
3. 故事线系统修复（点不开→弹 UI 展示主/支线、完成打勾、只记大事、填表时回写进展）
4. 缝合怪推进对接（主线完成→自动构造新主线、节奏 UI、开关默认开）
5. 自动生成故事线设置默认开启
6. 世界时间删除（交给 LLM，不用户操心）
7. 章名每章自动生成（现在只有第三章有）
8. 批量写作（选 1-10 章→后台生成 N 章，含章纲、可框选改、自动加章节）
9. 生成流程重构（章纲/作者指令默认收起、一键生成、删复杂角色调度弹窗、微调上移）

## 技术决策（侦察+讨论结论）
- **填表后台化**：选「任务表+轮询」，不选 SSE（关页面断流）。新建 `FillTask`（对齐 ImportTask 先例 schema.prisma:499-512），POST fill-all 查重→建任务→`void 后台跑`（本地 next 进程常驻）→返回 taskId；前端 2-3s 轮询 GET。已填标记 `.runtime/babylore-filled.json` 增量语义天然支持。
- **去重合并**：POST /api/characters/dedupe 同步跑。出现次数=全正文 name+aliases 计数（每章封顶 1 次）；龙套=count<3 且背景薄→tags 加「🎭龙套」（不删）；合并=isSimilarName 分组（归一化后编辑距离=0，不误并），主卡取内容更丰富者、aliases 合并、relationships.targetName 改指、被并卡 tags「🗂已合并」软删保留审计。
- **章名生成**：零成本方案——post-processor 保存处 title 为空/「第N章」占位时用 content 首段截 20 字兜底；批量任务可后续 LLM 补写。
- **故事线回写**：threadProgress（orchestrator.ts:328,366 `{storylineId, stage, progressNote}`）目前被丢弃（post-processor.ts:514→527）。新建 `src/core/pipeline/storyline-writer.ts`：stage 白名单（七要素）+ status==="active" + impactScore>=4 才写，覆写七要素 + chapterBindings push `{element, chapterId, chapterOrder, note}`；非法 storylineId 静默降级。
- **缝合怪对接**：storylines/[id] PUT status→completed 且 type=main 且 buildConfig.autoConstructNewMain→触发 storylines/generate mode:"newMain"（前主线已完结，构造承接新主线+支线）。节奏 `storylinePace:"fast|balanced|slow"` 存 Project.buildConfig Json（免迁移）。
- **批量写作**：任务表泛化（FillTask 加 taskType），前端弹窗选 1-10+作者指令→创建任务→后台逐章（建 StoryNode+章纲+正文）→进度胶囊。
- **生成流程重构**：章纲/世界时间等收进弹窗，正文上方只留极简条+「自动生成」主按钮；删 PreGenConfirm 复杂弹窗（留简单人物选项）；微调保留。**本轮做基础版**（世界时间删、章名兜底、批量写作任务化），完整重构（作者指令弹窗化/删 PreGenConfirm）下一轮。

## 本轮实施清单（P0）
1. FillTask 任务表 + fill-all 后台化 + 进度轮询 + 前端小胶囊提示
2. 自动去重合并（后端 + CharacterToolbar 按钮 + tooltip + 结果弹窗）
3. 故事线回写（storyline-writer + post-processor 接入）+ 完成触发新主线 + 节奏配置 + autoGenerateStoryline 默认开 + 文案

5. 章名首段兜底（post-processor）
6. 故事线 UI 打勾交互（StorylineList status 点击切换）

## 风险与取舍
- fire-and-forget 依赖本地进程常驻（重启悬挂任务轮询降级重触发）；合并为软删保留审计；自动新主线默认开但可关；默认开 autoGenerateStoryline 改变行为→文案说明。
