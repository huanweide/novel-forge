## 三、可立即落地的风格统一点

1. **卡片统一**：所有设置项/功能入口使用「图标 + 标题 + 描述 + 右侧操作」卡片。
2. **开关右对齐**：设置卡片内 Toggle 统一放右侧。
3. **底部三按钮**：设置弹窗/面板底部统一「重置默认 | 取消 | 保存设置」。
4. **折叠面板**：长表单项用可折叠分组（世界观设定、核心设定、补充备注等）。
5. **网格入口**：世界素材、AI 工具箱使用 2 列网格大按钮入口。
6. **右侧标签页**：AI 助手 / 工具箱 / 统计 三标签。
7. **主题色收敛**：以紫色为主色，橙色/绿色为辅助状态色。

## 四、风险与集成原则

- **数据库字段**：新增开关必须有 Prisma 字段 + 默认值 + API 写入。
- **默认值**：默认开启的功能要与现有行为一致，不能破坏旧项目。
- **已有功能合并**：参考站与我们功能同名但实现不同时，保留一个入口，旧数据要迁移或兼容。
- **不要照搬所有功能**：只集成用户截图中可见且与 novel-forge 定位一致的功能；语音校对、主题系统等若工程量过大，先预留接口。
