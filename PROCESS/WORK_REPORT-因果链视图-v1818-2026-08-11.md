# 工作单元报告：故事线工作台「因果链」第四栏（v1.8.18 / v1.9 第一步）

> 费曼式沉淀 · 零基础也能照做复现 · 写于 2026-08-11

## 一、干了什么（一句话）

给小说《新城·龙陨之地》所在平台的故事线工作台，加了一个新标签页「因果链」——把一条故事线（或整条主线树）里写作自动记录的关键情节节点，按时间顺序串成一条能看见「谁导致谁」的因果叙事链。

## 二、为什么这么做（底层原理，不用黑话讲）

**背景比喻**：你写长篇，主线像一条大河，支线像支流，伏笔像暗渠。以前工作台里，主线事件、支线事件、伏笔是分开三本账，你很难一眼看出「主线第三章那个转折，其实是支线二里埋的雷炸的」。

**v1.9 目标态**里记着一句话：「完整三栏因果链」。经过摸代码确认：工作台当时只有「要素 / 时间轴 / 线索集」三栏，时间轴是单线事件列表，**没有跨线、跨事件的因果串联**，数据层也没有「事件A导致事件B」这种字段。所以「因果链」不是凭空编的，是要把已有数据用新方式串起来。

**为什么选这条路（而非加数据库字段）**：常见做法是给事件表加「因果引用」字段（指向上一个事件）。但那要改数据库结构（schema 迁移），动线上 Postgres，风险高、且本次双门禁舒适区是「零 schema 变更」。而现有 `StorylineEvent` 已有 `position`（时间排序位）和 `kind`，足够按时间轴还原出一条"因→果"的叙事流——所以选了**零迁移、纯前端聚合**这条路，把风险压到最低。

## 三、方法工具与效果

### 1. 抽纯函数（可单测、组件零逻辑）
- 在 `src/lib/storyline-progress.ts` 末尾加 `buildCausalChain(storylines, selectedId)`：
  - 选中主线 → 取 `[主线, ...所有 parentId===主线 的子支线+伏笔]`；选中支线/伏笔 → 只取自身。
  - 把这些线的事件 `flatMap` 摊平，过滤掉 `CLUE`（线索不算因果节点），按 `position` 升序排。
  - 每个节点带上 `lineTitle`（来源线名）、`lineType`、`isMain`，方便前端标注归属。
  - 加了 `Array.isArray` 防御，传入 `undefined`/`[]` 安全返回 `[]`。

### 2. 工作台加第四栏
- `StorylineWorkbench.tsx` 的 `activeTab` 类型加 `"causal"`，tab 导航从三栏变四栏。
- 新增渲染块：纵向链表，每个节点一个卡片；节点间用「因 → 果」箭头串联；节点标注来源线标签（主线/支线/伏笔，不同颜色）+ 序号 + 类型图标（里程碑 star / 事件 arrowRight）。
- 顶部把未兑现的线索（CLUE）单独列成「悬而未决的因」，提醒作者别漏坑。
- 空状态：无线索时引导「去写一章」。

### 3. 单测补 4 条
- `src/lib/storyline-progress.test.ts` 追加 `buildCausalChain` 用例：主线聚合子树且排除 CLUE 且按 position 排序、节点带归属标识、支线只取自身、空/异常输入返回 `[]`。

### 效果数据
- TypeScript 编译：**0 错误**（修了一处隐式 any + undefined 崩溃）。
- 测试：**46 文件 403/403 全绿**（原 399 + 新增 4）。
- 零 schema 变更、零数据迁移。
- 提交 `5c866b5` 已推送 `huanweide/novel-forge` main。

## 四、关键取舍（为什么这么选，踩了什么坑）

- **没加数据库因果字段**：保持零迁移、双门禁稳。代价是"因果链"本质是"按时间的因果叙事流"，不是作者手动标注的硬因果边。若将来要"作者点一下说A导致B"，再补 schema 字段不迟。
- **踩坑 1（tsc 隐式 any）**：`flatMap` 里 `.filter((e) => ...)` 的 `e` 被 TS 判为隐式 any。修法：给 `s: any` / `e: any` 显式注解。
- **踩坑 2（undefined 崩溃）**：测试里传 `undefined` 时 `storylines.find` 直接崩。修法：入口加 `Array.isArray(storylines) ? storylines : []`，与项目里 `groupStorylinesByMain` 的防御一致。
- **未做的两项（重要，别误以为完成了）**：v1.9 目标态原话还记着「推进/试探墙」和「投票」。这两项在我全部记忆里只有"留作目标态"一句话、**零设计规格**，盲做必跑偏。本轮只落地了能确定、能零风险实现的「因果链」，另两项**等瑞宝宝给一句话定义再动手**。
