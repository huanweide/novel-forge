# 工作单元费曼报告：novel-forge v1.6.11 —— 星辰底座实机复检 + 双 P0 bug 修复 + 功能实用性董事会

> 读者：零基础大学生。能讲给大一新生听，才是真懂。
> 适用铁律：瑞宝宝「中文思维链 + 费曼报告 + 写入通报」；本文件常驻右侧产出面板，可独立查看。

## 一、干了什么（一句话）

用「星辰」项目（硬科幻世代飞船小说，目标 30 万字）当作真实续写测试底座，钉死并修复了两个会让写作中途崩溃的真 bug；再开樊氏 15 人格董事会，独立裁决 11 项功能「有意义 / 待优化 / 傻子功能」，砍掉全票傻子功能（游戏模式）、把限流降级，最后升版 v1.6.11 并推送到线上。

## 二、为什么这么做（第一性原理）

novel-forge 的核心承诺只有一句：**让本地作者高效写出连贯、长线、不崩坏的小说**。任何让作者写到一半报错的 bug，或把产品做成四不像的功能，都是绕路。

- 为什么用「星辰」真实长文测试，而不是只跑单元测试？因为 bug 往往藏在「真实长文 + 真实模型抽风」的组合里，单元测试覆盖不到。就像你只有真正开过车，才知道刹车在雨天会抖。
- 为什么开「多人格董事会」而不是一人拍脑袋？因为开发者容易爱上自己写的功能（自嗨），多人独立视角（技术 / 产品 / 风险 / 真实 / 用户 / 方向 / 尾部风险）互相拆台，才能把「看起来牛但没人用」的功能揪出来。

## 三、方法、工具与效果

### 1. 搭测试底座
- 星辰项目：`projectId=5550f26f-...`，已注入 1 章节 + 3 角色 + 3 世界卡 + 1 故事线。
- 第一章「启航」2390 字（真实模型生成，已验证 auto-confirm 链路）。
- 所有复检都通过 `localhost:3001` 真实 API + 真实 DeepSeek 模型，不 Mock。

### 2. 钉死两个 P0 bug（真实模型调用复检）
- **#113 章节摘要 500**：`summarize/route.ts` 把 LLM 返回的自由文本（如「林逸：疲惫，舰桥，决定继续探索」）当成 JSON 表格硬解析（`JSON.parse`），格式不对必崩 → 500。
  - 修复：改为存 `{ raw: 文本 }`，对齐全站 `post-processor` / `apply-extraction` 的约定。
  - 效果：复检 HTTP **200**，摘要正常生成。
- **#114 精修截断**：`refine` 要「重输出已有正文 + 增量」，但预算只按增量字数（默认 500）算，正文在已有内容处被截断、字数增长 0。
  - 修复：预算改为 `已有正文长 + 增量`（cap 5000 防超模型上限）。截断消除（实测 `truncated=undefined`）。
  - 但复检暴露新坑：模型有时把「续写」误解成「重写精简版」，只吐 1610 字（原文 2390 都没保住），静默丢前文。
  - 加 **L5-06 完整性保护**：新输出比原文短 10% 以上（且指令不是主动缩写）就降级保留原正文 + 告警。再加 **prompt 铁律**「一字不落保留已有正文」。
  - 效果：三道防线（F3 空响应 / L5-02 截断 / L5-06 完整性）全部实机验证，原正文不再被静默覆盖。

## 四、关键取舍（为什么这么选，不这么选会怎样）

- **游戏模式「隐藏入口而非删代码」**：删整个游戏子系统会牵动 game-engine / 路由 / 页面 / 测试，引发大量 tsc 失败与回归，违背「绝不偷工减料但也要稳」。隐藏入口让用户进不去（满足董事会「入口消失」），代码留着不添乱。
- **L5-06 阈值定 90% + 缩写白名单**：正常续写/修改输出应 ≥ 原长，短 10% 才判异常，避免误杀合法的「缩写本章」指令（指令含缩写/精简等词则跳过保护）。
- **限流不硬删、改 env 开关**：已写的限流代码在真有供应商限频需求时仍有价值，删了浪费；默认关则不误伤本地作者。

## 术语人话版（命名 ≠ 理解）

- **JSON.parse**：把一段文本当「结构化数据（像表格）」解析，文本不是那种格式就报错。LLM 返回的是自由口语，硬解析必崩。
- **max_tokens**：模型一次回答最多能吐多少「字」（token≈字）。预算不够就被从中间切断。
- **SSE**：服务器一边生成一边流式推给浏览器，像水龙头持续出水，而不是整桶倒给你。
- **第一性原理**：抛开「大家都这么做」，从最底层「这功能到底解决什么真问题」重新推导。
- **傻子功能**：看起来高级、但作者从来不用，或偏离产品核心让产品变四不像的功能。

## 反自欺闸门

- 两个 bug 修复都经过**真实模型调用复检**（HTTP 200 / truncated=undefined），不是只改代码就宣称修好。
- L5-06 保护用「强制短输出指令」实测触发，确认原正文保留（DB 终态 2390 字未丢），不是空想。
- 游戏模式是「隐藏入口」不是「删除代码」，这点如实说明，未伪装成彻底移除。
