## 一、干了什么（一句话）

把 novel-forge 从「一删就丢、一精修就静默覆盖、AI 乱填世界观」的不可控状态，升级为「删可恢复、精修可预览可撤销、AI 填表先待审」的可控写作工具，并补齐了限流重试退避与导出分层。

四个落地功能：
- **#123 删节点软删**：删除章节不再物理消失，进回收站可恢复。
- **#124 精修 diff 预览 + 撤销**：AI 改你文章前让你先看新旧对比，点头才采用。
- **#122 自动填表待审**：AI 自动从正文抽出的世界观设定先挂「待审」，你确认才入档。
- **#119/#120 LLM 重试退避 + 导出分层**：限流时优雅等待；导出格式分基础/进阶两层。
- （#121 伏笔检测改名「未收尾线索」，纯文案降低误解。）

## 二、为什么这么做（第一性原理）

### 1. 删除为什么必须软删？
类比：你写稿像在纸上写。原系统「删除章节」= 拿橡皮把那张纸彻底擦没，擦错就救不回。
正确做法 = 把纸移到「废纸篓」并贴个「已删」标签（tombstone 墓碑），需要时还能捡回来。
底层原理：数据库里给节点加一个 `deletedAt` 时间字段。删除 = 填上时间（标记），不真删；恢复 = 把时间清空；只有点「彻底清空」才物理删。所有「列出章节」的查询都加一句「只要没标记删除的」，被删的就对用户和 AI 隐身。

### 2. 精修为什么必须 diff 预览？
类比：你让助手改一段作文，他改完直接把原稿扔了换上新稿。你根本没机会比对，万一他改坏了你也看不见。
正确做法 = 改完后并排摆出「原稿 vs 新稿」，你点「应用」才替换，点「撤销」就还原。
关键修正：原系统精修会把「整本书目标字数（星辰=30 万字）」当续写长度传给 AI，导致 AI 预算永远爆上限、长章直接静默截断丢前文。本次把续写长度收敛成「每次最多 1500 字」，并超上限时弹明确告警（建议分段精修），不再悄悄截断。

### 3. 自动填表为什么必须待审？
类比：AI 读你的小说，自作主张往「世界观设定集」里塞它猜的角色/地点。猜错就污染了你的设定库。
正确做法 = AI 抽出的条目先标「待审」挂起，你点确认才转正入档；不确认就一直挂着，绝不自动进档。

## 四、关键取舍（为什么这样不做那样做）

1. **软删没做成「全站过滤」而是「关键读取点过滤」**
   全站有 30+ 处读 `storyNode`。若每处都加 `deletedAt:null`，改动面爆炸且易漏。
   决策：只过滤「用户可见的章节树」+「喂给 AI 的两条生成上下文」+「整本交付判定」这四处高价值读取点。内部统计类读取（如监控）即便含软删节点也不影响用户体验，留作后续。
   代价：极少数内部聚合可能短暂含软删节点，但用户无感。

2. **撤销用 PUT 还原原正文，而非调 rollback 接口**
   rollback 接口需要 `revisionId`，拿取麻烦。而前端删改前手里就有原 `selectedNode.content`，直接 `PUT` 把正文写回去最稳；且 refine 路由在覆盖前已自动快照旧版（pipeline 的 `snapshotRevision`），所以即使撤销后想反悔也能从版本历史找回新稿。双保险。

3. **精修续写字数从 30 万收敛到 1500，而非直接抬高上限**
   抬高上限可能超出模型 `max_tokens` 硬顶导致更诡异的截断。收敛续写增量既让绝大多数章节能正常精修，又只在超长章（>3500 字）才触发告警提示「分段精修」，符合「有意义、不绕路」。

4. **toast 加「动作按钮」能力（可复用增强）**
   原来 toast 只能显示文字。为支持「删除后撤销」按钮，给 `ToastOptions` 加了 `action?: {label, onClick}`，渲染层加按钮、点击自动关闭。这是通用能力，以后别处也能用。

## 五、复现步骤（照做即可验证）

```bash
cd /path/to/novel-forge
# 1. 同步数据库 + 重生成 client（#123 加字段后必做）
npx prisma db push && PRISMA_DISABLE_SAFE_DELETE=1 npx prisma generate
# 2. 门禁
SAFE_DELETE_DISABLE=1 npx tsc --noEmit   # 期望：无输出
npx vitest run                            # 期望：286 passed
# 3. 本地起服务（dev 端口 3001，DATABASE_URL 用 127.0.0.1:5432 避 IPv6）
npm run dev
# 4. 浏览器开 http://localhost:3001 → 进星辰项目工作区
#    - 左侧大纲删一个章节 → 弹「已移入回收站」带「撤销」；去 /recycle 看「节点回收站」可恢复/彻底删
#    - 选中章节点「续写/微调」→ 生成完弹 diff 预览，可应用/撤销
#    - 写一章确认后看世界卡是否进「待审」徽标
```
